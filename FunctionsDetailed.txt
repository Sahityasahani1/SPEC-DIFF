### 🔄 The Whole Process Explained (Step-by-Step)

Here is how a user request traverses the entire platform from initial click to 3D visualization and checkout:

```
[1. User Entry & Intent]
    │ (RecommendationForm / SearchEngineModal / Quick Prompts)
    ▼
[2. Frontend Validation & URL Sync]
    │ (App.jsx -> syncToUrl -> api.js: getRecommendations)
    ▼
[3. API Gateway & Security Layer]
    │ (FastAPI Router -> Limiter: 15 req/min -> Pydantic: HTML Sanitization)
    ▼
[4. Query Caching Check]
    │ (RecommendationCacheService: SHA-256 key check against Redis / Memory)
   ├─── [Cache HIT] ───────────────► Return cached JSON immediately (X-Cache: HIT)
   └─── [Cache MISS]
          ▼
[5. Deterministic Hard Constraint Filtering]
    │ (filter_service: SQL WHERE price <= budget AND ram >= req_ram AND in_stock = 1)
   ├─── [Zero Matches Found]
   │      │ (relaxation_service.py: diagnose_no_match)
   │      ▼
   │     Returns unmet constraint diagnostic & minimum INR budget adjustment
   └─── [Eligible Hardware Candidates Found]
          ▼
[6. Dense Semantic Vector Retrieval (RAG)]
    │ (vector_service: TF-IDF & Cosine Similarity against 384-dim documents)
          ▼
[7. Multi-Criteria 5-Factor Ranking]
    │ (ranking_service: Combines spec fit, semantic match, priority, rating, value)
          ▼
[8. Grounded Anti-Hallucination Explanation Synthesis]
    │ (explanation_service: Generates reasons, limitations, and catalog evidence)
          ▼
[9. Telemetry Enrichment]
    │ (benchmark_service: Geekbench/FPS + price_tracker: 30-day signal + store_deals)
          ▼
[10. Caching & Audit Logging]
    │ (cache_service.set in Redis + SQLAlchemy RecommendationLog insertion)
          ▼
[11. Frontend Presentation & Dynamic UI]
    │ (ProductCard 3D tilt + Laptop3DCanvas WebGL + CompareDock + CartDrawer)
```

1. **User Query Input:** The user fills out the [RecommendationForm.jsx](file:///c:/sahityaa/RAG%20Project/frontend/src/components/RecommendationForm.jsx) (e.g. Budget: ₹90,000, 16GB RAM, Use case: "4K video editing and rendering in Premiere Pro", Priority: "Performance").
2. **Frontend Dispatch & URL Serialization:** [App.jsx](file:///c:/sahityaa/RAG%20Project/frontend/src/App.jsx#L147-L160) serializes the state to URL query parameters for shareability, and calls [`getRecommendations()`](file:///c:/sahityaa/RAG%20Project/frontend/src/services/api.js#L6-L17).
3. **Gateway Protection:** FastAPI receives the request at [`/api/recommend`](file:///c:/sahityaa/RAG%20Project/backend/app/routers/recommend.py#L32-L39). The [SlowAPI limiter](file:///c:/sahityaa/RAG%20Project/backend/app/limiter.py) inspects the client IP, and [Pydantic](file:///c:/sahityaa/RAG%20Project/backend/app/schemas.py#L17-L25) strips any malicious scripts or HTML tags.
4. **Cache Lookup:** [`cache_service.generate_key()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/cache_service.py#L39-L51) creates a SHA-256 hash. If found in Redis or in-memory LRU, it returns instantly with header `X-Cache: HIT`.
5. **Deterministic Constraint Invariants:** [`filter_products()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/filter_service.py#L54-L85) queries the database with hard SQL bounds. Under no circumstance can a machine exceeding ₹90,000 or with less than 16GB RAM be returned.
   - *If 0 products match*, [`diagnose_no_match()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/relaxation_service.py#L7-L88) determines the bottleneck and suggests an actionable fix (e.g., *"Increase budget by ₹4,990 to unlock Lenovo LOQ"*).
6. **Semantic Vector Similarity (RAG):** Candidate products are converted to rich documents via [`create_product_document()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/vector_service.py#L10-L25). [`SemanticSearchEngine.compute_similarity()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/vector_service.py#L120-L136) measures cosine proximity between the user query and hardware text representations.
7. **5-Factor Hybrid Ranking:** [`rank_candidates()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/ranking_service.py#L84-L160) scores CPU capability, GPU tier, and computes:
   $$S_{\text{final}} = 0.35 \cdot S_{\text{req}} + 0.25 \cdot S_{\text{sem}} + 0.20 \cdot S_{\text{prio}} + 0.10 \cdot S_{\text{rat}} + 0.10 \cdot S_{\text{val}}$$
8. **Explanation Generation:** [`generate_explanation()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/explanation_service.py#L91-L149) creates verified reasons, limitations, and citations grounded directly in catalog specs.
9. **Hardware Telemetry Enrichment:**
   - [`get_benchmarks()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/benchmark_service.py#L58-L105) attaches Geekbench 6 single/multi scores and estimated gaming FPS.
   - [`get_price_signal()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/price_tracker_service.py#L14-L87) adds 30-day price trend curves and deal status badges (`STRONG_BUY`, `FAIR_VALUE`, etc.).
   - [`get_store_deals()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/store_deals_service.py#L92-L167) compiles Amazon, Flipkart, Croma, and Reliance Digital street prices.
10. **Storage & Delivery:** An audit record is logged into `RecommendationLog`, the response is cached in Redis via [`cache_service.set()`](file:///c:/sahityaa/RAG%20Project/backend/app/services/cache_service.py#L74-L90), and sent back to the browser.
11. **Frontend Rendering:**
    - [ProductCard.jsx](file:///c:/sahityaa/RAG%20Project/frontend/src/components/ProductCard.jsx) renders items with physics-based 3D tilt.
    - [Laptop3DCanvas.jsx](file:///c:/sahityaa/RAG%20Project/frontend/src/components/Laptop3DCanvas.jsx) renders the WebGL laptop with live spec telemetry on screen.
    - Users can add items to [CartDrawer.jsx](file:///c:/sahityaa/RAG%20Project/frontend/src/components/CartDrawer.jsx) with coupons or add them to [CompareDock.jsx](file:///c:/sahityaa/RAG%20Project/frontend/src/components/CompareDock.jsx) for 3-way specification diffing.
